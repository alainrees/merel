## Nieuw in Merel 0.1.11

- **Altijd de nieuwste versie.** Bij elke start kijkt Merel of er een nieuwe versie is. Is die er, dan werk je Merel eerst bij voordat je verdergaat. Zo komt beveiligingsherstel meteen bij iedereen aan. Zonder internet start Merel gewoon.

Vanaf 0.1.10 start Merel na **Opnieuw starten** vanzelf in de nieuwe versie; ⌘Q is niet meer nodig.

Bijwerken gaat vanuit Merel zelf: kies **Bijwerken** in het venster dat een nieuwe versie meldt.
